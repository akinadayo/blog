# C / PLAY DESK 実装・確認メモ

2026-09-05。C案の公開前検証記録。

## 実装

- 淡いドットのボード、クリーム色のメモ、濃緑と茶色のC案を共通デザインへ反映。
- ゲーム機の `breakout.exe` タイトルバーを削除。十字キーとA/Bキーを下げ、LCD枠から離した。
- Three.jsは固定バージョンをバンドルし、トップのゲーム機が見える時だけ読み込む。
- 印刷テクスチャの透明部分はalpha testで捨てる。透明な平面がLCDやキーを隠す不具合を回避。
- 自動デモは独立した物理モデル。30fps描画、画面外・非表示・ゲーム起動中は停止。低モーション設定では初期停止。
- 本物のブロック崩し、ランキング、リアクション、訪問番号、投票、ブックマーク、共有、記事URLは維持。

## 確認済み

- 1280pxのPC表示、390pxと320pxのスマホ表示。トップ・記事・プロフィール・技術一覧で横はみ出しなし。
- ゲーム機のLCD自動プレイ、画面タップで停止/再開、キー操作で傾斜/復帰。
- 傾斜 `x=0.370, y=0.400` でもLCDとキーが表示され、カメラ内に収まる。
- ゲーム起動、プレイ開始、ESC一時停止、閉じる操作。モーダル表示中はデモ停止。
- 投票前の結果・記事続きは非表示。確認で投票やスコア登録はしていない。
- `npm run test:breakout`：180秒、4面クリア、ミス0。30/60fps同じ進行。
- 確認用クリーンコピーで `npm run build` 成功。
- `npm run seo:check`：7ページ、3記事、RSS 3件、リダイレクト1件。
- `git diff --check` 成功。確認中のブラウザーにJSエラーなし。

## 既存の作業環境の注意点

元の作業フォルダーには未追跡の `* 2.tsx` / `* 2.astro` がある。
`src/pages/index 2.astro` が既に存在しない `AnimatedTitle` を参照するため、そのままの `npm run build` は失敗する。
これらの作業コピーは変更・移動・削除せず、除外した一時的なクリーンコピーでビルドした。
プレビューは同フォルダーの生成済みサイトをローカルで配信して確認した。

リポジトリ全体の `tsc --noEmit` は、既存の作業コピーの参照エラー、Astro設定の暗黙any、
RetroGameのuseRef初期値、sitemap型、Deno関数の環境差で未通過。今回の変更ファイルのTS/TSXエラーは報告されていない。
Three.jsの遅延読込チャンクはgzip約132KBで、Viteの500KB警告は残る。
低モーション設定とWebGL非対応時の2Dフォールバックは実装済みだが、実環境での切替確認は未実施。
